## Batch Rename 1.2.1

### 改进与修复

* 新增统一的文件夹重命名图标，窗口左上角与 `BatchRename.exe` 使用相同图标。

### 1.2.0 新功能

* 实时预览支持双击源文件名打开文件，并可右键直接重命名、移动或删除文件。
* 可将文件夹拖入实时预览区域，快速切换源文件夹。

### 1.1.4 改进

* 路径输入框现在同时支持手动输入和直接拖入文件夹，不再显示额外的拖放框。

### 1.1.3 改进

* 记住窗口的大小、位置和最大化状态，下次打开时自动恢复。
* 移除了“替换为”输入框下方的说明文字。

### 1.1.2 改进

* “忽略英文大小写”现在默认启用，界面同时移除了其说明文字。

### 1.1.1 修复

* 改用稳定的原生拖放组件，修复拖入文件夹时程序闪退的问题。

### 1.1.0 新功能

* 可将文件夹直接拖到“源文件夹”或“目标文件夹”拖放区域中选择路径（Windows）。
* 新增“忽略英文大小写”选项：删除前缀、删除后缀和查找替换均可不区分英文大小写。

## 下载

下载下方的 **BatchRename.exe**，双击即可使用，不需要安装 Python。

第一次打开时 Windows 可能提示「Windows 已保护你的电脑」（程序没有数字签名），
点「更多信息 → 仍要运行」即可。

## 功能

* 批量添加 / 删除前缀和后缀
* 删除 / 替换文件名中的任意文字
* 删除前后缀与查找替换可选择忽略英文大小写
* 批量移动到指定文件夹，可保留子文件夹结构
* 可通过拖放文件夹快速选择源文件夹和目标文件夹（Windows）
* 支持子文件夹，可按扩展名筛选
* 实时预览新旧文件名，自动标出重名、非法字符等问题
* 执行后可撤销
